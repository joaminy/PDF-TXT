# PDF → TXT 변환

PDF 안에 들어 있는 글자를 꺼내 텍스트(.txt) 파일로 저장하는 휴대폰용 웹앱입니다. 스캔하거나 사진으로 만든 PDF는 기기 안에서 문자인식(OCR)으로 읽습니다.

## 개인정보와 보안

- PDF는 **기기 안에서만** 읽고 처리합니다. 이 앱에는 파일을 받는 서버가 없습니다(정적 파일만 있음).
- **클로드 같은 AI 서비스를 거치지 않습니다.** PDF 안에 글자로 저장된 정보는 공개 PDF 엔진(PDF.js)으로 그대로 꺼냅니다. 이 경우에는 글자를 추측하지 않습니다.
- **문자인식도 기기 안에서 합니다.** 공개 문자인식 엔진 Tesseract(tesseract.js)가 휴대폰 브라우저 안에서 쪽을 그림으로 그려 글자를 읽습니다. Tesseract의 글자 인식기는 글자 모양을 미리 학습한 작은 신경망(LSTM)이지만, 인터넷이나 AI 서비스와는 통신하지 않습니다. 그림을 보고 추정하는 방식이라 틀린 글자가 생길 수 있으며, 앱은 문자인식으로 읽은 쪽과 신뢰도를 따로 표시합니다.
- 문자인식 엔진(약 8 MB)은 처음 쓸 때 **이 앱 주소에서만** 한 번 받아 기기에 보관합니다(외부 CDN을 쓰지 않음). 받은 파일은 빌드할 때 기록한 내용 해시와 맞을 때만 보관합니다.
- 앱 페이지에 콘텐츠 보안 정책(CSP)을 걸어 **다른 인터넷 주소와 통신하지 못하게** 막았습니다. 외부 글꼴·외부 스크립트·방문 분석 도구를 쓰지 않습니다.
- 한 번 열면 앱 파일이 기기에 보관되어 **인터넷 없이도(비행기 모드) 작동**합니다. 문자인식도 엔진을 한 번 받은 뒤에는 비행기 모드에서 작동합니다. 비행기 모드에서 변환이 되면 밖으로 보내지 않는다는 뜻입니다.
- 기기에 남는 것은 변환 설정과 앱 파일(받아 둔 문자인식 엔진 포함)뿐입니다. 넣은 PDF, 문자인식용으로 그린 쪽 그림, 변환 결과는 메모리에서만 다루며 앱을 닫으면 사라집니다(직접 저장한 TXT 파일은 남습니다). 암호는 PDF를 여는 데만 쓰고 저장하지 않습니다.
- Android에서 ‘공유 → PDF→TXT’로 보낸 PDF는 앱이 열릴 때까지 기기 안 임시 보관함에 잠깐 두었다가, 앱이 꺼내는 즉시 지웁니다.

## 기능

- 여러 PDF를 한 번에 변환하고, 하나씩 저장하거나 ZIP으로 모두 저장하거나 하나의 TXT로 합쳐 저장합니다.
- 줄바꿈 처리: **원본 줄 그대로** 또는 **문단으로 이어 붙이기**. 문단 모드는 줄 끝 위치로 문단을 추정하고, 한글 문서는 줄이 바뀐 자리의 띄어쓰기도 문서 안의 낱말을 근거로 되살립니다.
- 표의 칸은 탭으로 나눕니다(엑셀 등에 붙여 넣으면 칸이 나뉩니다). 두 단 편집은 왼쪽 단을 먼저 읽습니다.
- 쪽 구분 표시, 양식 입력란·글상자에 적은 글자 포함, 옛 Windows 메모장용 저장(BOM·CRLF)을 고를 수 있습니다.
- 암호 PDF를 열 수 있고, 글자가 없는 쪽(스캔·그림), 깨진 글자, 복사 제한을 알려 줍니다.

### 문자인식(OCR)

- **글자가 없는 쪽(스캔·사진)은 자동으로 문자인식**합니다(설정에서 끌 수 있음). 글자가 있는 쪽은 PDF 안의 글자를 그대로 씁니다.
- 결과 칸의 단추로 나중에 읽을 수도 있습니다: ‘글자 없는 쪽 문자인식으로 읽기’, 글자가 깨진 PDF용 ‘모든 쪽을 문자인식으로 다시 읽기’.
- 문서 언어: **자동**(한국어로 먼저 읽고 영어가 섞였으면 한국어+영어로 다시 읽어 더 믿을 만한 쪽을 고름), 한국어, 한국어+영어, 영어.
- 돌려 놓은 쪽(/Rotate)은 바로 세워 읽고, 거꾸로·옆으로 스캔된 쪽은 방향을 바꿔 시험한 뒤 바로 선 방향으로 다시 읽습니다.
- 글자 없는 사진 쪽처럼 신뢰도가 아주 낮은 쪽은 엉뚱한 글자를 넣지 않고 ‘찾지 못함’으로 알립니다.
- 쪽 구분 표시에 `(문자인식)`을 붙이고, 평균 신뢰도와 신뢰도가 낮은 쪽을 알려 줍니다.
- 문자인식 중에도 취소할 수 있으며, 그때까지 읽은 쪽은 남깁니다.
- 시험 결과(기계로 만든 깨끗한 글씨를 그림으로 바꾼 시험 문서, 띄어쓰기 제외 문자 오류율): 한국어 200 dpi 스캔 0.6%, 흐리고 살짝 기운 150 dpi 촬영풍 0.9%, 영어 0.0%, JPEG 2000 그림 0.6%, 거꾸로·옆으로 스캔된 쪽 0.0–0.6%. 실제 스캔·사진은 상태에 따라 이보다 나쁠 수 있습니다.

## 한계

- 문자인식은 추정이므로 틀린 글자가 생길 수 있습니다. 특히 흐린 사진, 아주 작은 글자, 한글과 영어가 섞인 줄, 표, 세로쓰기는 부정확하고, 손글씨는 거의 읽지 못합니다. 두 단으로 편집한 스캔 문서는 읽는 순서가 섞일 수 있습니다.
- 문자인식은 휴대폰에서 쪽마다 몇 초에서 수십 초가 걸립니다(거꾸로·옆으로 스캔된 쪽은 더 걸림). 쪽이 많으면 화면을 켠 채로 앱을 열어 두세요.
- PDF를 만들 때 글꼴의 문자 정보가 빠진 경우 글자가 깨질 수 있습니다(‘모든 쪽을 문자인식으로 다시 읽기’로 보완할 수 있음).
- 복잡한 표나 글상자가 많은 문서는 읽는 순서가 원본과 다를 수 있습니다.
- ‘문단으로 이어 붙이기’는 추정이므로 가끔 틀립니다. 특히 낱말 가운데서 줄을 바꾼 한글 문서(MS Word·웹 브라우저로 만든 PDF에 많음)는 띄어쓰기가 드물게 틀릴 수 있습니다. 정확해야 하는 글은 ‘원본 줄 그대로’를 쓰세요.

## 설치

- 지원 환경: iPhone·iPad는 iOS 16.4 이상의 Safari, Android는 최신 Chrome 또는 삼성 인터넷
- **iPhone (Safari)**: 주소를 열고 공유 버튼 □↑ → “홈 화면에 추가”
- **Android (Chrome·삼성 인터넷)**: 주소를 열고 “앱 설치” 또는 메뉴 → “홈 화면에 추가”
- 처음 한 번은 앱 파일(약 4.3 MB)을 받고, 문자인식을 처음 쓸 때 엔진(약 8 MB)을 한 번 더 받으므로 와이파이에서 여는 것을 권합니다. 설정의 ‘지금 미리 받기’로 엔진을 미리 받아 둘 수 있습니다. 앱이 새 버전으로 바뀌어도 받아 둔 엔진은 그대로 씁니다.
- 저장: iPhone은 ‘TXT 저장’을 누르면 공유 창이 열리고 “파일에 저장”을 고르면 됩니다. Android는 다운로드 폴더에 저장됩니다.

## GitHub Pages로 올리기

1. 새 저장소를 만들고(공개 저장소여도 됩니다. 저장소에는 앱 파일만 있고 PDF는 올라가지 않습니다), 이 폴더 안의 파일과 폴더를 저장소 맨 위에 그대로 올립니다.
2. 저장소의 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 고르고 Save를 누릅니다.
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 에서 열립니다.
4. 같은 주소(`<아이디>.github.io`)의 다른 앱과 함께 써도 서로의 보관함·설정을 건드리지 않습니다.

## 파일 구성

- `index.html`, `app.css`, `app.js` — 화면
- `textcore.js` — 글자 정리 핵심(줄·문단·표·한글 띄어쓰기·양식 입력값·문자인식 결과 정리)
- `ocr.js` — 문자인식(쪽 그리기, 언어 고르기, 방향 시험, 엔진 받기)
- `ocr-assets.json` — 문자인식 엔진 파일 목록(크기·내용 해시)
- `sw.js` — 오프라인용 서비스 워커(파일 목록과 내용 해시를 담음. `tools/build.py`가 만듦)
- `vendor/pdfjs/` — PDF.js와 CMap·표준 글꼴·그림 해독기(wasm)
- `vendor/tesseract/` — tesseract.js, 문자인식 엔진(SIMD용·일반용), 한국어·영어 학습 데이터
- `tools/` — 앱을 고친 뒤 다시 묶을 때 쓰는 도구(앱 실행에는 필요 없음). 파일을 고쳤다면 `cd tools && npm install && python3 build.py`로 `sw.js`를 다시 만들어야 휴대폰에 새 버전이 들어갑니다.

## 포함한 오픈소스

- [PDF.js](https://github.com/mozilla/pdf.js) 6.5.438 (pdfjs-dist legacy build) — Apache-2.0
- PDF.js에 딸린 CMap(Adobe), 표준 글꼴(Foxit, Liberation), 그림 해독기(OpenJPEG BSD-2-Clause, PDFium JBIG2 BSD-3-Clause, qcms MIT)
- [tesseract.js](https://github.com/naptha/tesseract.js) 7.0.0과 tesseract.js-core 7.0.0(Tesseract OCR 엔진) — Apache-2.0. 학습 데이터 처리 버그 한 곳을 빌드할 때 고쳐 넣습니다(`tools/build.py` 참고).
- 한국어·영어 학습 데이터: [tessdata_best](https://github.com/tesseract-ocr/tessdata_best)(Apache-2.0)의 정수형 변환본(@tesseract.js-data/kor·eng 1.0.0)
- 각 라이선스 전문은 `LICENSES/`에 있습니다.
